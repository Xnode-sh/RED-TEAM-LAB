# Первый полезный разбор — на проверку оператору

Статус: не опубликовано. Перед публикацией подготовить изображение с командами.

Linux тормозит? Начни с трёх наблюдений

Открой терминал и выполни по очереди:

uptime
free -h
df -h /

• uptime — покажет время работы и среднюю нагрузку за 1, 5 и 15 минут. Эти числа нужно оценивать с учётом числа процессоров и текущей работы.
• free -h — покажет память. Смотри на available: это оценка памяти, доступной для запуска программ. Кеш сам по себе не означает проблему.
• df -h / — покажет свободное место в файловой системе, где находится корень системы. Отдельный /home нужно проверять отдельно.

Проверили на нашей Debian 13: около 9,7 GiB доступной памяти и 851 GiB свободного места на корневой файловой системе. В момент проверки нехватки этих ресурсов не видно.

Это первый шаг, а не полная диагностика: он не проверяет здоровье диска, температуры и причины зависаний. Команды только читают состояние.

Сохрани этот пост, чтобы начать проверку без установки дополнительных программ.
