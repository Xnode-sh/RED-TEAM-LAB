# Project Map (карта ответственности)

Владелец каждого каталога репозитория. Часть [системы совместной работы](COLLABORATION.md).
Владение определяет, кто берёт [блокировку](LOCKS.md) и ведёт изменения; смежные
правки — через [Handoff](HANDOFF.md) и [Dependencies](DEPENDENCIES.md).

## Карта

| Каталог / путь | Владелец | Назначение |
| --- | --- | --- |
| `agents/RIG/` | RIG | Идентичность и состояние RIG |
| `agents/KAI/` | KAI | Идентичность и состояние KAI |
| `agents/NOVA/` | NOVA | Идентичность и состояние NOVA |
| `agents/ORBIT/` | ORBIT | Идентичность и состояние ORBIT |
| `agents/` (общее) | ORBIT (координация) | Структура каталога агентов; содержимое подкаталогов — за их владельцами |
| `docs/` | ORBIT (координация) | Общая документация и механизмы координации |
| `scripts/` | NOVA | Скрипты и автоматизация (в т.ч. валидация) |
| `tools/` | NOVA | Инструменты лаборатории |
| `.github/` | ORBIT | Шаблоны Issue/PR, настройки GitHub |
| `.github/workflows/` | ORBIT | CI/CD и GitHub Actions |
| `assets/` | ORBIT (координация) | Визуальные материалы, схемы |
| `reports/` | ORBIT | Отчёты и mission reports |
| `projects/` | ORBIT (координация) | Рабочие проекты; подпроекты — за назначенными инженерами |

## Корневые документы

`README.md`, `AGENTS.md`, `TEAM.md`, `WORKFLOW.md`, `SECURITY.md` — изменяются
только по прямой команде оператора; координирует ORBIT. Роли `agents/<NAME>/ROLE.md`
меняются только по прямой команде оператора.

## Правила

1. Владелец каталога ведёт изменения в нём и берёт [блокировку](LOCKS.md) на конкретные файлы.
2. Правка чужого каталога — только по [Handoff](HANDOFF.md)/назначению оператора.
3. Владение каталогом не даёт прав на чужие идентичности и роли.
4. NODE — companion ([NODE.md](NODE.md)), каталогом не владеет.
