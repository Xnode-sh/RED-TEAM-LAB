# Стандарт README — RED └•TEAM•┐ lab™

Верх: компактный собственный баннер (1280×240–360), название проекта, одно предложение о назначении, ссылка на штаб. NODE занимает не более 12–15% ширины баннера; в статусе — 24–32 px. Все существенные сведения остаются текстом.

Порядок разделов: назначение → фактический статус и ограничения → возможности → поддерживаемые платформы → зависимости → установка → минимальный рабочий пример → конфигурация → архитектура → проверка/тесты → workflow и вклад → лицензия → ссылки.

Для каждого проекта команды установки и запуска сверяются с реальными файлами. Не копировать отсутствующий requirements.txt, не заявлять CI или стабильность без проверки. Не выдумывать лицензию; если LICENSE отсутствует, указать необходимость решения владельца.

Статус: «экспериментальный», «в разработке» или «поддерживается» только с подтверждением владельца/фактами. Указываются реальные ограничения платформы. У netmon — Windows и права администратора; у wifi-audit — оценка паролей, без обещаний аудита радиоэфира; у sockpuppet-hunter — вероятностные связи, без утверждения идентичности человека.

Визуальные токены: #09090b / #202126 / #f4f1ec / #a91d32. Моноширинная типографика, один красный акцент, тонкие линии. Без внешних изображений, декоративных badge-wall, анимации, скриптов, foreignObject и удалённых шрифтов. SVG: viewBox, title, обычные path/rect/circle/text. README читается и без картинок.

Ссылки ведут на реальные репозитории. Приватные репозитории и сведения из них не включаются в публичные материалы. Существующая полезная документация переносится с сохранением содержания, а не заменяется общим шаблоном.

Архитектура команды в баннерах, схемах, карточках и общих перечнях: RIG — SYSTEM / KAI — FIELD / NOVA — TOOLING / ORBIT — CLOUD / INTEGRATION. Полные роли и дома сверять с TEAM.md; маскот NODE и существующие качественные элементы сохранять.

Полное публичное представление лаборатории обязательно разделяет ENGINEERING NODES (RIG / KAI / NOVA / ORBIT) и LAB COMPANION (NODE — Mascot & Visual Status Daemon). NODE не пятый инженер. Роль ORBIT: Cloud Workspace & Integration Engineer. Идентичность и состояния NODE: [NODE.md](NODE.md).
