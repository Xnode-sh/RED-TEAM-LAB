# Task Queue

Единый реестр задач RED └•TEAM•┐ lab™ — общий источник истины по текущей работе.
Часть [системы совместной работы](COLLABORATION.md).

Каждый агент видит здесь: **свои** задачи (по полю «Владелец»), **ожидающие**
(`pending`), **завершённые** (`done`) и **кому передана** работа (поле «Передана кому»).

## Статусы

- `pending` — ожидает взятия в работу;
- `active` — выполняется владельцем;
- `blocked` — заблокирована (указать причину в примечании и в [HANDOFF.md](HANDOFF.md));
- `done` — завершена и влита/закрыта.

## Правила ведения

1. Одна задача — одна строка; у каждой уникальный `ID` вида `T-<номер>`.
2. Менять статус и владельца может только текущий владелец или ORBIT при интеграции.
3. Передача владения оформляется по [HANDOFF.md](HANDOFF.md); поле «Передана кому» указывает принимающего.
4. Не дублировать задачи; завершённые не удалять, а переводить в `done` (история сохраняется).
5. Обновлять в рамках [Session Checkpoint](CHECKPOINT.md) — без дублирования информации.
