# NODE — LAB COMPANION

**RED └•TEAM•┐ lab™ Mascot & Visual Status Daemon**.

“A tiny daemon that keeps the lab alive.”

NODE — лабораторный mascot/companion и визуальный status daemon. Не пятый инженер, не человек-сотрудник и не инженерный узел. Инженерные узлы — RIG / KAI / NOVA / ORBIT; полная [архитектура лаборатории](../TEAM.md) включает их и отдельного companion NODE.

## Идентичность

- Tiny ultra-cute fox-cat cyber daemon.
- Japanese cyber-minimal aesthetic.
- Black / graphite / white with red neon accents.
- Torii motif; выразительные минимальные красные глаза; пушистый лисий хвост.
- Спокойный, технический, слегка игривый характер.

Собственный нативный [SVG NODE](../assets/rig-node.svg) и изображение в [баннере](../assets/rig-banner.svg) сохраняют существующий визуальный язык. Внешний хостинг изображений не используется.

## Визуальные состояния

`IDLE / WORK / BUILD / TEST / OK / ERROR / SLEEP / THINK / ALERT / HAPPY`.

Состояния описывают лабораторию или проект, а не полномочия сотрудника. Использовать как визуальные метки рядом с текстовым статусом; OK не заменяет подтверждённые проверки, ERROR не скрывает причину сбоя. Исполняемый status daemon и автоматическое получение состояния в этом репозитории не реализованы.
