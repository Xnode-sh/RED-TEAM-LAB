# Безопасность

Никогда не сохранять в Git и не публиковать:

- API keys, passwords, OAuth tokens, cookies и session credentials;
- private keys, SSH private keys и signing keys;
- `auth.json`, `credentials.json`, `.env` и другие файлы с секретами.

`.gitignore` исключает типичные секреты и локальные файлы, но не проверяет содержимое файлов и не удаляет уже отслеживаемые данные. Перед commit необходимо проверить весь staged diff и список файлов.

Использовать переменные окружения или локальные файлы вне Git для передачи секретов. В документации допустимы только очевидные placeholders без действующих credentials.

При обнаружении опубликованного секрета немедленно уведомить оператора и отозвать или заменить credential. Переписывание истории требует прямой команды оператора.

Без прямой команды оператора запрещены force push, удаление всего репозитория, изменение ролей и вмешательство в чужие рабочие зоны. NOVA работает внутри `~/RED-TEAM-LAB`; изменение Android system, использование root, изменение bootloader и factory reset запрещены без прямой команды.
