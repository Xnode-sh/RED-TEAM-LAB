# RIG — скриншоты и запись экрана

Кнопки справа в нижней Polybar:

- **PNG**: левая кнопка — весь экран, правая — выбор области. PNG без потерь.
- **REC**: левая кнопка — начать/завершить запись. Красный REC с таймером означает
  активную запись. Правая кнопка открывает папку видео.

Скриншоты: `~/Изображения/RED-TEAM-LAB/`; записи: `~/Видео/RED-TEAM-LAB/`.
Используются XDG Pictures/Videos; при других настройках папки могут отличаться.
Файлы сохраняются с уникальным именем, существующие файлы не заменяются.

Запись: X11, исходный размер рабочего стола, H.264 CRF 18, ultrafast,
два потока и nice=10, 30 fps CFR, AAC 192 kbit/s с системного monitor-источника.
Микрофон не записывается. Если monitor недоступен, создаётся видео без звука
с уведомлением. CRF 18 — высокое качество с потерями, не lossless.
При высокой нагрузке возможны повторы кадров; короткий тест не доказывает
плавность под нагрузкой. Остановка через SIGINT позволяет завершить MP4.

Проверка 2026-10-08: PNG сохранён, MP4 корректно читается ffprobe,
H.264 1366×768, 30/1 fps, 174 кадра / 5,8 секунды, AAC присутствует.
Первая настройка veryfast давала низкую частоту; заменена на ultrafast
и укорочено обнаружение входов. Длительная запись не проверялась.

Скрипт: `scripts/capture.py`. Журнал в `$XDG_RUNTIME_DIR/rig-capture-UID/record.log`.
FFmpeg 7.1.5 и три зависимости скачаны из Debian apt и распакованы локально
в `recorder-runtime/`, исключённый из Git; системные пакеты не менялись.
Повторная подготовка: `bash tools/i3/setup-recorder.sh`.

Для применения кнопок: `python3 tools/local-ai/install-launcher.py` —
сохраняет резервные копии конфигов и запускает панели через i3.
Материалы с экрана остаются локальными; автоматической отправки нет.
