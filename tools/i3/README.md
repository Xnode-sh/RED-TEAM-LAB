# RIG — i3 / Polybar / Cava / Picom

Тёмная тема RED TEAM LAB: красный и бирюзовый акценты, зазоры между окнами,
полупрозрачный Kitty и мягкий dual-Kawase blur. Предназначена для X11 / i3 4.24,
Polybar 3.7 и Picom 12 из Debian 13.

Установить: `bash tools/i3/install-theme.sh`. Пароль sudo вводится в локальном
терминале. Установка пакетов: polybar, cava, picom, rofi, feh, librsvg2-bin,
pavucontrol. Скрипт сохраняет заменяемые файлы в
`~/.config/rig-backups/<дата-время>/`, устанавливает конфиги, проверяет i3 и
активирует тему, если i3 уже запущен. В XFCE нужно выйти и выбрать i3 при входе.

Полная шпаргалка — [hotkeys.txt](hotkeys.txt); на рабочем столе открыть
**Super+F1**, прокручивать стрелками/PageUp/PageDown, закрыть клавишей Q.
Super означает клавишу Windows. Буквенные сочетания привязаны к физическим
клавишам, поэтому действуют и при русской раскладке.

Super+Shift+Q и Super+Shift+D сохранены как привычные альтернативы.
Super+Space теперь открывает приложения; прежнее переключение типа фокуса
перенесено на Super+Ctrl+Space. Снимки запускаются при отпускании клавиш.

Две панели CONTROL DECK, рассчитанные на экран Acer 1366×768.

Сверху: меню приложений, пять всегда видимых кнопок рабочих столов, заголовок
окна, терминал, файлы, браузер, Telegram, Cava, громкость, часы, трей и питание.
Рабочие столы обновляются по событиям i3. На значке RED / LAB левая кнопка
открывает приложения, правая — окна. Cava повторно фокусирует уже открытое
окно. Громкость: левый клик — mute, колесо — изменение, правый — микшер.
Часы по клику переключают дату. Значок питания открывает меню; правая
кнопка блокирует экран. Выход/перезагрузка/выключение требуют отдельного
выбора в меню, чтобы случайный клик не прерывал работу.

Снизу: CPU, RAM, температура процессора, свободное место, SYSTEM / ACER /
DEBIAN, состояние сети, скорость приёма/отправки и питание. Температура
показывает максимум датчиков coretemp/k10temp/zenpower и меняет цвет при
70°C/85°C; недоступный датчик показывает `--`, а не выдуманное значение.
Сеть без SSID/IP на самой панели. Скорость — сумма физических интерфейсов,
K/M означают KiB/s и MiB/s. Нет батареи — отображается AC.

Клик по температуре или SYSTEM открывает системный обзор. Правая кнопка на
SYSTEM — настройки дисплея. Сеть: левая кнопка — редактор подключений,
правая — локальные подробности в терминале. Питание AC/батареи — настройки
энергосбережения. Полная информация остаётся в локальном окне.

Cava анализирует воспроизводимый звук через PulseAudio/PipeWire-Pulse. При
тишине пустая визуализация нормальна. Cava не запускается автоматически.

Полупрозрачность Kitty — 87%, Thunar — 94%, Telegram — 96%. Для остальных
приложений текст остаётся непрозрачным. Picom работает с GLX и слабым blur
strength=3; дополнительных постоянных визуализаторов нет. Если GLX выдаёт
ошибку, посмотреть журнал, прежде чем менять backend. Можно убрать blur,
установив `method = "none"` и `blur-background = false` в picom.conf.

Журналы: `${XDG_RUNTIME_DIR:-/tmp}/rig-i3-$UID/polybar.log` , `polybar-telemetry.log` и `picom.log`;
журнал установки — `tools/i3/theme-install.log`. Стартовый скрипт перезапускает
только собственные процессы; существующий сторонний Picom не завершается.
XFCE и его менеджер входа остаются установленными.

Восстановление: скопировать нужные файлы из резервной папки в `~/.config/`,
перезапустить i3. Для перехода обратно в XFCE сохранить работу, выйти из
сеанса и выбрать XFCE на экране входа. Системные пакеты удалять не требуется.
Исходный простой конфиг i3 сохранён в `config.previous`; первая версия
Polybar — в `polybar/config.simple.ini`.
