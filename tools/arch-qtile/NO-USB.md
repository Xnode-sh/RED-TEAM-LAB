# Arch + Qtile без флешки

Оператор запросил этот маршрут 2026-10-09. Фактическая система — Debian 13.7,
BIOS, один HDD с корнем ext4 /dev/sda1 и swap /dev/sda5. Свободное место внутри
ext4 не является свободным местом в таблице разделов.

## Подготовка загрузки

Запустить `sudo bash tools/arch-qtile/prepare-hdd-live.sh` в локальном терминале.
Скрипт проверяет ISO, сохраняет GRUB, копирует ISO в /boot/iso и добавляет
пункт «RIG: Arch Live from HDD (RAM)». Debian остаётся загрузкой по умолчанию.
Скрипт не перезагружает и не форматирует диск. Реальная загрузка ещё не проверена.

При перезагрузке показать GRUB удержанием Shift и выбрать этот пункт.
После загрузки проверить сеть, lsblk и параметры copytoram. Перед изменением
раздела с ISO убедиться, что Live полностью работает из RAM и этот раздел
не используется в качестве источника Live.

## Установка и сохранение данных — актуальный маршрут 2026-10-09

Подготовлен `install-from-debian.sh`: установка из действующего Debian через
проверенный Arch ISO. На подтверждённом Acer используется только прежний
swap `/dev/sda5` (12 770 607 104 байт); `/dev/sda1` и его границы сохраняются.
Исходный домашний каталог остаётся на месте. По уточнению оператора устанавливается
только основное: Arch, Qtile, Kitty, сеть, звук и Codex; AI, браузер и инструменты
сборки откладываются. Новый минимальный домашний каталог находится в
`/var/lib/rig-arch/home` на большом разделе и монтируется как `/home`.
Проект и `.codex` доступны через ссылки на исходные каталоги, без копирования
моделей и всей истории. Сохраняются настройки Kitty и Git. Пакетный кэш и
новый swap-файл также находятся на большом разделе. Остановленная неполная
копия домашнего каталога сохранена отдельно, не удалена.

Минимальный набор пакетов требует около 2,1 GiB по метаданным текущего
репозитория; установщик проверяет размер и свободное место перед записью.
Корень Arch ограничен размером прежнего swap-раздела: это рабочий переходный
вариант, а не прежняя схема корня 100 GiB. Большие пользовательские файлы и
модели не занимают место в этом корне.

Установка требует root и смонтированного bootstrap Arch в
`/mnt/rig-arch-bootstrap`. Она не запускается сама в ранее подготовленном ISO.
Сценарий рассчитан на конкретные UUID и размер раздела этого Acer; повторный
запуск после форматирования старого swap отвергается.

После установки создаётся отдельный пункт GRUB `RIG: Arch Linux + Qtile`.
Первый запуск выбирается однократно. Сервис `rig-arch-first-boot` проверяет
корень, графический процесс Qtile, NetworkManager, Codex, PipeWire и Intel;
только после успешной проверки делает Arch постоянной загрузкой. Результаты:
`/var/lib/rig-arch/evidence` на сохранённом разделе данных.

Сохранённый домашний каталог не является внешним бэкапом: оба раздела на одном
HDD. Исходный Debian сохранён для возврата при ошибке. Удалять его до приёмки
Arch и создания внешней копии нельзя.

## Прежний вариант с уменьшением раздела — не выполняется

Прежняя инструкция полной очистки HDD неприменима: без внешнего бэкапа она
уничтожит единственную копию пользовательских данных. Не запускать её.

Следующий этап требует отдельной проверки в Live: офлайн-проверка ext4,
уменьшение существующей файловой системы и её раздела с неизменным начальным
сектором, создание отдельного раздела Arch не менее 100 GiB. Нужны точные
границы из таблицы разделов; текущую /dev/sda1 нельзя уменьшать смонтированной.
Изменение разделов без внешней копии несёт риск потери данных при ошибке или
отказе HDD. Автоматического скрипта переразметки в этом комплекте нет.

Debian и домашние данные сохранять до успешной загрузки Arch, проверки Qtile
и переноса пользователя UID 1000, проекта, конфигураций и моделей. Не копировать
Debian /usr, /lib и весь /etc поверх Arch. Секреты вводить только локально.
