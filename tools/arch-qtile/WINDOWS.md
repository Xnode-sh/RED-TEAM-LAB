# Управление окнами RIG / Qtile

Активный минимальный конфиг: `minimal-config.py`. Применён на Acer / Arch
2026-10-09. Используется Qtile BSP (`name="dwindle"`, `fair=False`, `ratio=1`):
новое окно делит область активного окна поровну. Широкая область делится
слева/справа, высокая — сверху/снизу; новое окно справа или снизу.
Закрытие возвращает место соседу. Это перенос основной логики dwindle,
не полная реализация Hyprland: направления разделений сохраняются,
вставка не зависит от положения курсора, Wayland-анимации, pseudo mode
и перенос плиток мышью не реализованы.

| Сочетание | Действие |
| --- | --- |
| Super + Enter | Kitty |
| Super + Space | Приложения |
| Super + стрелки / H J K L | Фокус в направлении |
| Super + Shift + стрелки / H J K L | Переставить плитку; переместить плавающее окно |
| Super + Ctrl + стрелки / H J K L | Изменить размер плитки; изменить размер плавающего окна |
| Super + V / Super + Shift + Space | Плавающий режим |
| Super + F | Полный экран |
| Super + Q | Закрыть окно |
| Super + S / O | Повернуть разделение |
| Super + Shift + N | Нормализовать размеры дерева |
| Super + Tab / Shift + Tab | Следующее / предыдущее окно |
| Super + Alt + Tab | Список окон Rofi |
| Super + 1…9, 0 | Рабочий стол 1…10 |
| Super + Shift + 1…9, 0 | Перенести окно и перейти за ним |
| Super + Ctrl + Shift + 1…9, 0 | Перенести окно без перехода |
| Super + [ / ] | Предыдущий / следующий рабочий стол |
| Super + Ctrl + R | Перечитать конфиг |
| Super + ЛКМ / ПКМ, перетаскивание | Плавающее перемещение / размер средствами Qtile |

Первые четыре стола сохраняют имена CODE, LAB, COMMS, SYS для сохранения
текущих окон при перечитывании конфига; затем 5…10.

Проверено: импорт Python, отсутствие повторов сочетаний, десять групп,
геометрия трёх окон (половина слева, две четверти справа), возврат места
при закрытии; живой IPC подтвердил `dwindle` и десять групп после reload.
`qtile check` проверил Python и зависимости виджетов; mypy/stubtest
не установлены, проверка типов пропущена. Ручная проверка каждого
сочетания и перетаскивания не выполнялась.

Резервная копия активного конфига перед применением:
`~/.config/rig-backups/qtile-dwindle-20261009-024943/config.py`.
Для отката скопировать её в `~/.config/qtile/config.py` и нажать
Super + Ctrl + R.
