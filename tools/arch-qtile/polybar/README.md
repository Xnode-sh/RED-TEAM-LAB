# Актуальное оформление: овальные островки

По последнему уточнению оператора: отдельные овальные блоки вместо длинной
полосы. Слева приложения, один номер рабочего стола и окна; по центру часы;
справа только значки сети/звука/управления/питания и раскладка/трей.
Колесо над номером переключает столы; нажатие открывает сетку выбора.
Снизу компактная овальная телеметрия. Цвета: графит #171923,
лаванда #b4a4ed, мята #89ddca; розовый только для ошибок.
Четыре Polybar: control, clock, status, telemetry. Радиус 14 px,
высота 28 px сверху и 24 px снизу; Lucide 11 px. enable-struts=false,
Qtile фиксирует Gap 40/32 px, чтобы три верхних окна не суммировали struts.
Карточки 300 px, подписи минимальные. Backup перед изменением:
~/.config/rig-backups/oval-20261009-032805/.
Снимок подтвердил округлые блоки и правильный порядок окон; логи без ошибок.
Чёрные углы без композитора устранены shape.py: он задаёт настоящую
скруглённую X11 bounding region, launcher применяет её после запуска.
Зависимость — уже установленный xcffib с X11 Shape extension.

Далее сохранено описание предыдущих этапов для истории.

# RIG / SIGNAL DECK

Две Polybar для Acer / Arch + Qtile X11, экран 1366×768.
Фактически применены 2026-10-09; после отзыва оператора оформление
переработано, а по уточнению оператора сделано компактным: верхняя панель
30 px, нижняя 22 px, отдельные контрастные блоки, часы по центру.
Значки — единый контурный набор Lucide 0.468.0 (шрифт для Polybar и SVG
18 px для карточек); подписи JetBrains Mono/DejaVu Sans.

По нажатию LAB, раскладки, сети, звука, CONTROL, часов и питания открываются
привязанные к нажатому блоку GTK3 карточки. В них есть приложения,
операции с окнами, сети Wi-Fi, громкость/микрофон, системные показатели,
яркость, календарь и подтверждаемое завершение сеанса. Карточки шириной
300 px открываются под панелью и закрываются по Escape/клику снаружи.
Реальные Escape и клик снаружи проверены через X11; все семь карточек
открывались без ошибок. Прерывающие сеанс и сеть операции не выполнялись.

Верхняя панель: меню приложений/окон, десять рабочих столов с индикатором
занятости, меню управления раскладкой, заголовок окна, Kitty, Codex,
проект, PNG, помощь, громкость, EN/RU, часы, трей, завершение сеанса.
Заголовок окна перенесён в центр нижней панели.
Нижняя: реальные CPU/RAM, температура coretemp, состояние NVIDIA,
свободное место Arch и раздела данных, сеть, трафик, яркость и uptime.
Управление — [HOTKEYS.txt](HOTKEYS.txt).

## Установка и повторное применение

Нужны polybar, python/libqtile, kitty, rofi, wpctl, nmcli, brightnessctl,
scrot, htop, notify-send, GTK3/python-gobject/python-cairo и шрифты
JetBrains Mono/DejaVu/Lucide.
На этой машине Polybar 3.7.2 установлен через отдельный кэш
`/var/cache/pacman-rig`: старый `/var/cache/pacman/pkg` на сохранённом
разделе не позволял загрузчику pacman создавать файлы. База pacman
с административным доступом работала; обновление её формата не выполнялось.

Скопировать содержимое этого каталога в `~/.config/polybar/rig/`.
Скопировать `lucide.ttf` в `~/.local/share/fonts/` и выполнить
`fc-cache -f ~/.local/share/fonts`. SVG и карта `lucide.json` должны
оставаться рядом со скриптами. Версия набора зафиксирована, атрибуция
и лицензия — `LUCIDE-LICENSE`; источник пакета
https://cdn.jsdelivr.net/npm/lucide-static@0.468.0/.
Использовать `../minimal-config.py` в `~/.config/qtile/config.py` и
`../minimal-autostart.sh` в `~/.config/qtile/autostart.sh`, предварительно
сохранив текущие конфиги. Qtile без нативной панели принимает EWMH struts
от Polybar. Launcher запускается при входе через Qtile autostart.
При ручном перезапуске использовать
`qtile cmd-obj -o root -f spawn -a 'bash ~/.config/polybar/rig/launch.sh'`.
Launcher хранит PID только своих двух панелей и логи в
`$XDG_RUNTIME_DIR/rig-polybar/`, не завершает чужие Polybar.

## Проверки и ограничения

- Python и Bash синтаксис, импорт Qtile, существование всех модулей.
- Две живые панели и загруженные шрифты; итоговые логи без error/warning.
- Меню Rofi визуально проверено в живом X11 и закрыто. Отдельная команда
  `rofi -rasi-validate` аварийно завершилась; её результат не использован
  как доказательство валидности темы.
- Десять кликабельных команд рабочих столов; переключение на LAB через
  тот же обработчик и возврат в исходную группу.
- Девять источников телеметрии прочитаны; CPU/traffic работают потоково.
- Локальный снимок экрана проверен: обе панели помещаются, окна получают
  отступы сверху/снизу через Qtile.
- mypy/stubtest отсутствуют; проверка типов пропущена. Долгая работа и
  следующий вход в сеанс ещё не проверены. Выход/reboot/poweroff, Wi-Fi off
  и другие прерывающие работу действия при проверке не выполнялись.

Плавающие окна пользователь может размещать поверх зарезервированной
области; плитки учитывают struts. Скриншоты сохраняются только локально
в `~/Pictures/RED-TEAM-LAB`. Панель не запускает запись экрана.

Резервная копия перед применением:
`~/.config/rig-backups/signal-deck-20261009-025816/`.
Предыдущая версия Polybar перед переработкой сохранена в
`~/.config/rig-backups/signal-deck-redesign-20261009-030425/`.
Перед компактной версией с Lucide:
`~/.config/rig-backups/compact-lucide-20261009-031927/`.
Для отката восстановить `config.py` и `autostart.sh` в
`~/.config/qtile/`, завершить две панели через сохранённые PID и
перечитать Qtile. Пакеты при откате удалять не требуется.
