# Миграция с одной Silicon-Power 16 ГБ

Оператор располагает только этой флешкой. Предлагается Ventoy: один раздел одновременно содержит ISO Arch и зашифрованный архив данных. Raw-запись ISO через dd после создания архива запрещена: уничтожит архив.

## Проверено 2026-10-08

- USB Silicon-Power16G: 15 833 497 600 байт (14,7 GiB), сейчас /dev/sdb.
- На USB один NTFS-раздел с меткой `22631_3155_Compact_x64`; данные ещё не просмотрены/не сохранены и устройство не изменялось.
- Домашний каталог без downloads: 11 018 113 024 байт (~10,3 GiB).
- ISO Arch: 1 640 497 152 байт (~1,53 GiB).
- /usr/local: около 447 МБ; доступная часть /etc: около 10 МБ. Полный размер защищённых /etc и /root требует root. sudo -n запросил пароль; секреты не читались.
- Предварительно пользовательские данные, настройки и ISO помещаются. Окончательный контроль ёмкости выполняется скриптом офлайн от root с запасом 1 GiB. Если не помещается, скрипт останавливается; Debian не удалять.
- Ventoy 1.1.17 скачан из официального GitHub Release; SHA-256 `7fb4ed08cef6a6b4d39dd19260d8c80291a78dfdf9af7d461571e23cbbc43805` совпал с опубликованным sha256.txt. Архив распакован в исключённом downloads/. Ventoy на флешку ещё не устанавливался.

## Последовательность

1. До любой записи USB разрешить доступ и сохранить её текущие данные на внутреннем HDD, проверить копию. Пароль sudo вводить в локальном терминале, не в чат.
2. После отдельного разрешения на перезапись именно Silicon-Power установить проверенный Ventoy (MBR для существующего BIOS-режима), затем скопировать ISO, подпись и комплект миграции на первый раздел. Windows-файлы остаются в проверенной копии на HDD; эту копию также включить в миграционный архив, если требуется её сохранение.
3. Размер этой дополнительной USB-копии необходимо включить в расчёт. Если вместе с ней резервная копия не помещается на флешку, не удалять её автоматически: требуется выбор оператора или другой маршрут хранения.
4. Проверить повторно SHA-256 ISO на USB и успешно загрузить Arch из меню Ventoy. HDD не изменять до проверки загрузки и архивирования.
5. В Arch Live смонтировать Debian read-only, первый раздел Ventoy — read-write. Ventoy может использовать ISO из этого же раздела; его служебный раздел не форматировать.
6. Запустить `bash backup-live.sh /mnt/debian /mnt/backup --migration` из отдельной копии комплекта. Архив содержит весь домашний каталог (кроме повторных downloads), /etc, /usr/local и /root. Это миграционный архив, а не полный образ Debian для отката.
7. Проверить расшифровку, tar-структуру, SHA-256 и извлечение нескольких файлов (проект, история Codex, модель). Сравнить с исходниками. Извлекать пробные файлы на HDD в отдельный каталог только после перемонтирования для этой проверки; перед финальным архивом изменения требуют повторной оценки. Можно вместо извлечения сравнить хеши потоковых данных из архива с оригиналом, не меняя Debian.
8. Только после проверенной копии заменить Debian на Arch по INSTALL.md. Домашние файлы восстановить, пакеты установить заново; /etc и /usr/local не копировать поверх Arch целиком.
9. После восстановления не удалять архив с USB до прохождения всех проверок нового окружения.

Важно: единственная флешка одновременно является установочным носителем и единственной внешней резервной копией. При ошибке архивирования или чтения не начинать удаление HDD.
